# Changelog

## v1.0.0 - 2026-11-25

- 将仓库重新定位为纯粹的 Embedded Framework & Project Template Knowledge Base。
- 移除此前 Skill、C 编码规范和 POSIX Skill 相关内容。
- 新增 MCU/RTOS/Linux 多平台指南：Bare Metal、STM32Cube、FreeRTOS、Zephyr、NuttX、RT-Thread、ESP-IDF、Pico SDK、Buildroot、Yocto。
- 新增跨平台架构设计文档：分层、BSP/HAL/Driver、组件化、事件驱动、设备/会话管理、Transport、资源预算、Boot/OTA。
- 新增成熟中间件与框架目录和源码阅读路线。
- 新增 12 类工程模板，覆盖 MCU、RTOS、Vendor SDK 与 Embedded Linux。
- 提供一个 Host 可编译的 Ring Buffer 组件示例。
