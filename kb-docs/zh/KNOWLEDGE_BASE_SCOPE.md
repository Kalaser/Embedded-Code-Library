# 知识库维护范围

## 收录标准

优先收录满足至少三项条件的项目：

1. 有明确的上游组织/维护团队。
2. 有正式文档和可定位的源码入口。
3. 有真实可运行的 examples/samples/demos/templates。
4. 有清晰的模块边界、平台适配或构建机制。
5. 有持续版本发布、CI 或社区维护活动。
6. 具备在多个产品工程中复用的潜力。

## 不收录

- 仅有单个演示文件、无构建说明的零散代码。
- 只有营销性介绍、没有源码或技术文档的产品页面。
- 无法确认来源和许可证的代码片段。
- 与本知识库目标无关的语言学习课程和 AI Skill 文件。

## 更新策略

- 每季度检查上游链接和 release 状态。
- 每次模板修改更新 CHANGELOG。
- 平台指南注明适用 release 或检查日期。
- 上游 API 变化时先更新源码阅读入口，再更新模板。
- 旧模板若不再适用于当前 release，标记为 deprecated，不静默删除。
