# Upstream Source Snapshot

Checked on: 2026-11-25

This is a discovery snapshot, not a guarantee that every upstream branch or license remains unchanged. Re-check the exact tag/commit before each import.

- Apache NuttX repository README identifies POSIX/ANSI orientation and Apache-2.0 or compatible licensing: https://github.com/apache/nuttx
- Zephyr repository metadata identifies the primary repository and Apache-2.0: https://github.com/zephyrproject-rtos/zephyr
- FreeRTOS kernel licensing documentation states MIT and warns that demos may include separately licensed third-party software: https://freertos.org/libraries/license.html
- RT-Thread README states Apache-2.0; vendor BSP content can have separate licenses: https://github.com/RT-Thread/rt-thread
- Arm CMSIS documentation states Apache-2.0: https://arm-software.github.io/CMSIS_5/latest/General/html/index.html
- libopencm3 README identifies LGPL-3.0-or-later: https://github.com/libopencm3/libopencm3
- TinyUSB upstream LICENSE identifies MIT: https://github.com/hathach/tinyusb/blob/master/LICENSE
- lwIP upstream README identifies a BSD license: https://github.com/lwip-tcpip/lwip/blob/master/README
- littlefs repository identifies BSD-3-Clause: https://github.com/littlefs-project/littlefs
- MCUboot LICENSE identifies Apache-2.0: https://github.com/mcu-tools/mcuboot/blob/main/LICENSE
- LVGL README identifies MIT for LVGL core and separate licensing for LVGL Pro: https://github.com/lvgl/lvgl
- ETL repository metadata identifies MIT: https://github.com/ETLCPP/etl
- Unity LICENSE identifies MIT: https://github.com/ThrowTheSwitch/Unity/blob/master/LICENSE.txt
- Ceedling repository metadata identifies MIT: https://github.com/ThrowTheSwitch/Ceedling
- libopencm3 template describes itself as a clone-and-go project template: https://github.com/libopencm3/libopencm3-template
- PlatformIO examples repository provides examples for multiple platforms and frameworks: https://github.com/platformio/platformio-examples

License status in `components.json` is intentionally conservative. “Catalog-only” entries are not approved for product use.
